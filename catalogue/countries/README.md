# Country catalogues

Each reviewed country uses an uppercase ISO3 directory containing
`sites.geojson` and `units.yaml`. The starting catalogue has no real sites.
See `fixtures/catalogue/XXX/` for an explicitly synthetic file format example.
Register all source IDs in `../sources.yaml` and all terms in `../taxonomy.yaml`.
Country facet IDs are lowercase; the `country` property stays uppercase ISO3.
